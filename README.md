# Cristian Páez | Frontend Developer Portfolio

Personal portfolio built with React and Vite to showcase my skills, projects, and professional profile as a Junior Frontend Developer.

## About the project

This portfolio presents my journey as a frontend developer, highlighting my experience building web interfaces with HTML, CSS, JavaScript, and React.

The website includes information about my background, technical skills, personal projects, and contact details.

## Features

- Responsive layout designed for desktop, tablet, and mobile screens.
- Spanish and English language selector.
- Personal introduction and professional profile.
- Technical skills section.
- Project cards with links to GitHub repositories.
- Contact links for email, WhatsApp, and LinkedIn.
- Dark theme with purple and blue accents.
- Smooth scrolling and reduced-motion accessibility support.

## Getting started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository and navigate to the project folder:

```bash
git clone YOUR_REPOSITORY_URL
cd mi-portafolio
npm install
npm run dev
```

Open the local URL displayed in your terminal to view the application.
